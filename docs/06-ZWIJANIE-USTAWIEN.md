# Zwijanie ustawień finałów — Relaksmisja

Po udanym zapisie ustawień finałów formularz nazwy sezonu, dat i kortów zwija się. Przycisk „Edytuj” otwiera tę samą sekcję z zapisanymi wartościami. Przycisk „Zwiń” pozwala ją zamknąć ręcznie. Nieudany zapis pozostawia formularz otwarty.

Już skonfigurowany sezon pokazuje początkowo zwiniętą sekcję. Brak nazwy sezonu lub terminów powoduje jej automatyczne otwarcie. Zarządzanie sezonami, kopie i przycisk konfiguracji drabinki pozostają dostępne.

Zmiana wyłącznie w interfejsie Relaksmisji; bez zmian danych, API i SmartLigi. Kontrola TypeScript i build Relaksmisji zakończone poprawnie. Nie powtarzano długich testów całego systemu ani nie wykonywano zapisów na produkcyjnych danych.
